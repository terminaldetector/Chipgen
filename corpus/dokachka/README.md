# Корпус докачки

267 треков, 22 саундтреков, 144056 нот. Genesis 183, NES 84.

Вторая половина обучающего корпуса. Живёт на отдельной ветке, чтобы не лежать весом в основном репозитории — докачивается по необходимости.

## Что это и чем отличается от ядра

Не «худшие» треки и не брак. Разбиение сделано по **предельному вкладу**: сколько трек приносит паттернов, которых ещё нет в наборе. Треки ядра приносят в среднем 135 новых токенов, треки докачки — 40.

Важное, что показал аудит и что стоит знать перед тем, как что-то отсюда выбрасывать: **дубликатов в корпусе нет вообще**. Проверено пятью наборами признаков; медианное сходство Jaccard между любыми двумя треками 0.000, максимум по тысячам пар 0.235. Здесь нет ни одного трека, который просто повторяет то, что уже есть в ядре. Разница только в плотности нового материала на трек.

Практически это значит: ядра хватает, чтобы модель усвоила идиому (67% всего словаря паттернов). Докачка нужна, когда нужен хвост — редкие ходы, нетипичные прогрессии, то, что встречается в корпусе один раз.

## Как подключить

```bash
git fetch origin claude/corpus-dokachka
git checkout origin/claude/corpus-dokachka -- corpus/dokachka
```

После этого `score_model.corpus_paths()` подхватит их вместе с ядром — обход идёт по всему `corpus/` рекурсивно, отдельной настройки не нужно.
